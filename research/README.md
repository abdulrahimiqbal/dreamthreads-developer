# Dream meaning global monthly searches and search trends (2026)

This directory publishes the open data behind DreamThreads' connected comparison
of 15 exact dream-related Google search terms in the United States.

- Canonical analysis and citation: <https://mydreamthreads.xyz/dream-trends/2026>
- Data: [`dream-search-interest-2026.csv`](dream-search-interest-2026.csv)
- Analysis date: 2026-07-30
- Geography: United States
- Search type: Google Web Search
- Window: five years ending 2026-07-30
- Shared comparison anchor: `nightmare meaning = 100`

## Does “dream meaning” have one global monthly-search count?

No single public, authoritative number exists independently of geography, date
range, language, match rules, close variants, and Search Network settings.
Google Trends reports normalized relative interest rather than absolute search
counts. Google Ads Keyword Planner can provide rounded average monthly estimates
for a specified configuration, but those estimates answer a different question.

The CSV therefore contains a **relative search-interest index**, not global
monthly search volume. An index of 258 means that the selected term had about
2.58 times the five-year average relative interest of the shared anchor inside
this connected analysis. It does not mean 258 searches, 258,000 searches, or a
global monthly total.

## Method

Google Trends permits five terms in one comparison. Four comparisons were run,
each containing `nightmare meaning` as the shared anchor. For every group, each
term's five-year average was divided by that group's anchor average and multiplied
by 100. Values were rounded to the nearest whole number.

Reproducible comparison links and the limitations of this approach are published
on the [canonical DreamThreads analysis](https://mydreamthreads.xyz/dream-trends/2026#methodology).
